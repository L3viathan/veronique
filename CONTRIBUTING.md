# Contributing

I'm happy to get help with Véronique.

If you want, you may join [the Discord server](https://discord.gg/atvuVztJcN),
but it's not required for contribution.

Before you open a PR, please ask in the corresponding issue. Issues are often
not very fleshed out because I usually know what I mean. If there isn't an
issue for the thing you want to work on, feel free to create one, but wait with
any implementation until the issue is approved.

## Generative AI/LLM policy

I do not accept any contributions that contain content generated by LLMs. This
also includes all written communication on GitHub. I will close any pull request,
issue, or discussion that does not comply to this policy.
